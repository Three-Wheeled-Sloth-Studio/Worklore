# WorkLore Project References

This folder is the durable project memory for WorkLore. It follows the project reference pattern maintained in `Three-Wheeled-Sloth-Studio/Agent-Academy`.

Use YAML for structured project state and Markdown for explanatory material. Keep entries factual, current, and concise.

Do not store secrets, real vault contents, resumes, API keys, provider logs, or machine-only credentials in `refs/`.

## Reading Order

1. `project.yaml`
2. `agents.yaml`
3. `planning/roadmap.yaml`
4. `planning/todos.yaml`
5. Relevant architecture, product, implementation, UI, and testing files
6. `handoffs/currentHandoff.md`
