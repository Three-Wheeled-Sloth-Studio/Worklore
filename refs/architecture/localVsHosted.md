# Local and Hosted Boundaries

## Local and Authoritative

- User-selected WorkLore vault
- Imported source copies
- Stories, roles, interviews, job records, voice instructions, and entity registry
- Stable private tokens and rehydration mappings
- SQLite indexes and local extraction caches
- Ollama requests and responses
- User preferences and provider selection
- Local Git scans and commit evidence

## Hosted Only When the User Chooses It

- Gemini requests using a user-supplied API key
- Manual workspace packages uploaded by the user to ChatGPT, Claude, or Gemini
- Future WorkLore-hosted inference using paid credits

## Explicitly Out of Initial Scope

- Live vault synchronization
- Hosted user accounts
- Automatic cloud backup
- LinkedIn publishing and scheduling
- GitHub account authorization and private repository scanning through GitHub APIs

Cloud submissions must display the active privacy mode and apply the user's durable entity-redaction preference, with a per-request override.
