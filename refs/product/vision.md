# Product Vision

WorkLore helps people recover the useful professional stories buried across resumes, job descriptions, writing samples, Git history, and memory.

The product should turn thin claims into durable, evidence-backed stories by identifying gaps and conducting focused interviews. Those stories become reusable source material for interview preparation, resume work, job matching, and public professional content.

The primary promise is control. Users own the vault, can inspect and edit the canonical records, can choose local or hosted models, and can see how private entities are mapped or redacted.

The first success condition is simple: a user can import a resume, select a bullet, answer a manageable set of questions, and leave with a useful story note that is more complete, more credible, and easier to reuse than the original bullet.
