# Security Policy

WorkLore handles resumes, career history, repository activity, and other potentially sensitive material.

Do not commit real WorkLore vaults, imported documents, entity mappings, provider logs, API keys, or other user data to this repository.

## Reporting a Vulnerability

Please use GitHub private vulnerability reporting from the repository Security tab when available. Do not open a public issue for a vulnerability that could expose user data, credentials, or private repository information.
